# ☕ 브릿지 커피 — 단골 적립 스탬프

작은 카페를 위한 **종이 도장판 대신 쓰는 스탬프 적립 웹앱**입니다.
음료 한 잔에 스탬프 하나, **10개를 모으면 무료 음료** 한 잔을 드립니다.

인터넷 연결도, 설치도, 회원가입도 필요 없습니다.
**파일을 두 번 클릭하면 바로 열립니다.**

---

## 특징

- 📱 **휴대폰 화면 기준** — 손가락으로 누르기 편한 큰 버튼
- 🧊 **글래스모피즘** — 반투명 유리 느낌의 디자인
- 🔌 **인터넷 없이 동작** — 서버도, 데이터베이스도 없음
- 🔒 **손님 정보는 전화번호 뒷 4자리만** — 이름·생년월일·주소를 받지 않음
- 📤 **엑셀로 백업/복원** — 데이터가 날아가도 되돌릴 수 있음
- 🛠 **프레임워크 없음** — HTML·CSS·JavaScript만으로 만든 파일 2개

---

## 파일 구성

| 파일 | 무엇인가요 |
|---|---|
| `index.html` | **손님 화면** — 뒷 4자리를 넣으면 내 스탬프를 보여 줍니다 |
| `admin.html` | **사장님 화면** — 비밀번호로 잠겨 있고, 적립·취소·백업을 합니다 |
| `운영안내.txt` | **직원용 안내서** — 개발을 몰라도 읽고 따라할 수 있게 정리 |
| `CLAUDE.md` | 이 프로젝트의 작업 규칙 |

## 바로 써 보기

1. 이 저장소를 내려받습니다. (초록색 **Code → Download ZIP**)
2. 압축을 풉니다. **두 파일은 같은 폴더에 있어야 합니다.**
3. `admin.html`을 **크롬(Chrome)** 으로 엽니다.
4. 비밀번호 **`1234`** 를 누릅니다.
5. 손님 번호 `1234` 를 누르고 **[적립 +1]** 을 눌러 보세요.
6. 새 탭에서 `index.html`을 열고 `1234` 를 넣으면 스탬프가 보입니다.

> ⚠️ **크롬 또는 엣지(Edge)를 쓰세요.**
> 사파리·파이어폭스는 파일을 직접 열었을 때 저장이 막힐 수 있습니다.

## 화면 소개

### 손님 화면 (`index.html`)

- 휴대폰 번호 **뒷 4자리**만 넣으면 지금 모은 스탬프를 보여 줍니다
- 동그라미 10개와 진행 막대로 한눈에 확인
- 10개를 다 모으면 **축하 화면 + 무료 음료 교환권**
- **30초 뒤 저절로 첫 화면으로** 돌아갑니다 (다음 손님이 앞 사람 정보를 못 보게)
  - 천천히 보시는 손님은 화면을 한 번 누르면 시간이 다시 늘어납니다
- 사장님이 적립하면 **1초 안에 숫자가 저절로 올라갑니다**

### 사장님 화면 (`admin.html`)

- 비밀번호 4자리로 잠금
- 바쁠 때 빠르게 누르는 **큰 숫자 키패드**
- **[적립 +1]** / **[실수했어요 −1]** / **[무료 음료 드림 · 사용 완료]**
- 같은 손님에게 **1분 안에 두 번 적립하면 한 번 더 물어봅니다** (중복 적립 방지)
- 사용 완료는 되돌릴 수 없어서 **두 번 확인**합니다
- **[📱 손님 화면 처음으로 되돌리기]** — 대기 손님이 있을 때 즉시 전환
- 오늘 적립한 횟수 표시 (날짜가 바뀌면 자동으로 0부터)

## 데이터가 어디에 저장되나요

**기기 안(브라우저)에만 저장됩니다. 인터넷으로 아무것도 보내지 않습니다.**

저장되는 내용은 이게 전부입니다.

```
브릿지커피_스탬프          →  { "1234": 3, "5678": 9 }   (뒷번호 : 개수)
브릿지커피_마지막적립날짜  →  { "1234": "2026-07-28" }
브릿지커피_오늘적립        →  { 날짜: "2026-07-28", 횟수: 12 }
```

이름·생년월일·주소는 받지도, 저장하지도 않습니다.

### ⚠️ 꼭 지켜야 하는 3가지

1. **두 파일을 같은 폴더에 두고, 같은 브라우저로 여세요.**
   브라우저가 다르면 서로 다른 저장소를 보게 됩니다.
2. **시크릿 모드(비밀 모드)로 열지 마세요.** 창을 닫으면 전부 사라집니다.
3. **"쿠키 및 사이트 데이터 삭제"를 하지 마세요.** 스탬프가 같이 지워집니다.

## 백업과 복원

기기를 바꾸거나 브라우저 기록을 지우면 스탬프가 사라집니다.
**일주일에 한 번** 백업해 두세요.

### 내려받기

사장님 화면 아래 **[⬇️ 내려받기 (엑셀로 열려요)]** 를 누르면
`브릿지커피_적립현황_2026-07-28.csv` 파일이 만들어집니다.

| 손님 번호 | 현재 스탬프 개수 | 마지막 적립 날짜 |
|---|---|---|
| 0007 | 5 | 기록 없음 |
| 0123 | 3 | 2026-07-28 |
| 7890 | 1 | 2026-07-28 |

- 엑셀에서 **한글이 깨지지 않고**, `0007`의 **앞자리 0도 지워지지 않습니다**
- 엑셀에서 숫자를 고친 뒤 다시 불러와 **바로잡을 수도 있습니다**

### 되살리기

**[📂 파일에서 되살리기]** → 받아 둔 `.csv`(또는 `.json`) 파일 선택 → 두 번 확인.

> 지금 기기에 있던 스탬프는 **모두 지워지고** 파일 내용으로 바뀝니다. 합쳐지지 않습니다.

## 설정 바꾸기

메모장으로 파일을 열고 아래 줄을 찾아 숫자만 바꾸면 됩니다.

| 바꾸고 싶은 것 | 어디에 | 찾을 글자 |
|---|---|---|
| 사장님 비밀번호 | `admin.html` | `var 사장님비밀번호 = '1234';` |
| 자동으로 돌아가는 시간 | `index.html` | `var 자동돌아가는시간 = 30;` |
| 중복 적립을 막는 시간 | `admin.html` | `var 겹침막는시간 = 60 * 1000;` |
| 무료 음료에 필요한 개수 | **두 파일 모두** | `var 스탬프총개수 = 10;` |

> 스탬프 개수를 바꿀 때는 **`index.html`과 `admin.html` 양쪽 다** 고쳐야 합니다.

## 만든 방법

- **HTML · CSS · JavaScript** 만 사용 (프레임워크·빌드 도구 없음)
- 각 화면이 **파일 하나**로 완결 — 나눠진 파일이 없습니다
- 저장은 브라우저의 `localStorage`
- 두 화면은 **1초에 한 번 같은 저장소를 확인하는 방식**으로 서로 통신합니다
- 글꼴: 고운 돋움 → 맑은 고딕 순서로 사용
- **코드와 주석이 전부 한국어**입니다 (비개발자가 직접 고칠 수 있도록)
