# 브릿지카페 단골 적립 스탬프

음료 1잔에 스탬프 1개, 10개를 모으면 아메리카노 1잔 무료!
가게에서 쓰는 **단골 적립 스탬프 웹앱**입니다. 서버나 설치 없이 HTML 파일만으로 동작합니다.

- 손님 화면: `index.html`
- 사장님(직원) 화면: `admin.html`
- 매장 운영 방법: `운영안내.txt`

## 이렇게 동작해요

1. 손님이 음료를 사면, 직원이 **사장님 화면**에서 손님의 휴대폰 번호 **뒷 4자리**를 넣고 **[적립]**을 눌러요.
2. 10개가 되면 "무료 음료 제공 대상입니다" 알림이 떠요. 음료를 드린 뒤 **[사용 완료]**를 누르면 0개로 초기화돼요.
3. 손님은 가게 기기의 **손님 화면**에서 번호 4자리를 넣고 **[확인]**을 누르면 자기 스탬프를 볼 수 있어요. 10개를 모으면 꽃가루가 날리는 축하 화면이 떠요.

## 주요 기능

### 사장님 화면 (`admin.html`)
- 비밀번호 4자리로 들어가기 (3번 틀리면 30초 잠김), [잠그기]
- **적립 / 취소(-1) / 사용 완료 / 개수만 보기** 버튼 (바쁠 때 빠르게 누르도록 크고 단순하게)
- 실수 방지 장치
  - 같은 번호로 **1분 안에 또 적립**하면 "방금 적립했습니다. 계속할까요?" 확인
  - 번호가 4자리가 아니면 버튼이 눌리지 않음
  - [사용 완료]는 확인창에서 한 번 더 확인
  - 10개가 넘게 적립되지 않음
- 오늘 적립한 총 횟수 (취소하면 같이 줄어요)
- **기록 백업**: 파일로 저장 / 불러오기, 오래되면 경고

### 손님 화면 (`index.html`)
- 번호 뒷 4자리를 넣으면 동그라미 10개(5개씩 2줄)에 스탬프 개수만큼 색이 채워져요.
- "3개 모았어요! 7개 더 모으면 아메리카노 1잔 무료" 안내 문구
- 10개를 모으면 축하 화면과 꽃가루
- 휴대폰 기준(폭 390px), 하늘색 + 크림색 **글래스모피즘** 디자인, 글꼴은 고운 돋움(없으면 맑은 고딕)

## 기록은 어디에 저장되나요?

스탬프 기록은 **사장님 기기의 브라우저 안에만** 저장돼요. 인터넷 서버로 나가지 않아요.

| | |
|---|---|
| 새로고침해도 유지되나요? | 네, 같은 기기·같은 브라우저·같은 주소에서 열면 유지돼요. |
| 다른 기기에서 보이나요? | 아니요. 다른 기기에서는 기록이 없어요. |
| 손님이 자기 휴대폰으로 QR을 찍으면? | 그 휴대폰에는 기록이 없어서, 개수 대신 **"스탬프는 가게에서 확인해 드려요"** 안내가 나와요. |
| 브라우저 데이터를 지우면? | 기록이 사라져요. **[백업 파일 저장]**으로 가끔 저장해 두세요. |

> 손님 화면이 진짜 개수를 보여주려면 **사장님 화면과 같은 인터넷 주소(같은 폴더)**에 두고 **사장님 기기에서** 열어야 해요.

## 사용 방법

1. `admin.html`과 `index.html`을 **같은 곳**에 두고 브라우저로 열어요. (휴대폰에서 쓰려면 무료 인터넷 주소에 올려서 그 주소로 여는 방법이 가장 쉬워요.)
2. 사장님 화면에서 비밀번호를 넣고 들어가요. 항상 **같은 주소, 같은 브라우저**를 쓰세요.
3. 자세한 운영 방법과 손님 안내 문구, 문제가 생겼을 때 확인할 것은 [`운영안내.txt`](./운영안내.txt)에 있어요.

## 설정 바꾸기

각 파일 맨 위 `★ 설정` 칸에서 한국어 주석을 보고 고칠 수 있어요.

| 바꾸고 싶은 것 | 파일 | 위치 |
|---|---|---|
| 가게 이름, 모아야 하는 개수, 보상 | `index.html`, `admin.html` | 기본 설정 |
| 사장님 비밀번호 | `admin.html` | `사장님비밀번호` 줄 |
| 꽃가루 개수·색 | `index.html` | `꽃가루개수`, `꽃가루색` |
| 1분 중복 확인 시간 | `admin.html` | `중복확인_밀리초` |
| 화면 색깔 | 두 파일 | `<style>` 맨 위 `:root` |

> 개수나 가게 이름을 바꿀 때는 두 파일의 숫자·글자를 **서로 똑같이** 맞춰 주세요.

## 개인정보와 보안

- 손님 정보는 **휴대폰 번호 뒷 4자리와 스탬프 개수**만 저장해요. 이름 등은 받지 않아요. 개수가 0이 되면 그 기록은 지워져요.
- **진짜 손님 번호를 코드 파일(`index.html` 등)에 적지 마세요.** 파일을 인터넷에 올리면 누구나 소스 보기로 읽을 수 있어요.
- 사장님 비밀번호는 파일 안에 적혀 있어서 소스 보기로 보여요. **화면 잠금 정도로만** 생각하세요. 인터넷에 올리는 경우 기본 비밀번호는 꼭 바꿔서 쓰세요.
- 백업 파일에는 손님 번호가 들어 있으니 인터넷에 올리거나 남에게 보내지 마세요.
- 뒷 4자리만으로는 손님을 완벽히 구분할 수 없어요. 서로 다른 손님의 뒷자리가 같으면 기록이 합쳐질 수 있어요.

## 참고: 구글 스프레드시트 연결 (지금은 사용하지 않음)

손님이 자기 휴대폰으로도 스탬프를 보게 하려고 구글 스프레드시트를 장부로 쓰는 코드(`서버코드.gs`)와 연결 부분을 만들어 두었지만, **현재는 꺼져 있어요.**
두 화면 설정의 `서버주소`가 비어 있으면 동작하지 않고, 위의 "사장님 기기에만 저장" 방식으로 쓰여요.
이 방식은 손님 번호가 구글 서버에 저장되므로 쓰기 전에 보안 설정과 개인정보 위험을 꼭 검토해야 해요.

## 파일 구성

```
단골 적립 스탬프/
├─ index.html      손님 화면 (스탬프 확인, 축하 화면)
├─ admin.html      사장님 화면 (적립, 취소, 사용 완료, 백업)
├─ 운영안내.txt    직원용 매장 운영 안내
├─ 서버코드.gs     (사용 안 함) 구글 스프레드시트 연결용 코드
├─ 자료/           기획에 쓴 정책 시트
├─ CLAUDE.md       이 프로젝트를 AI와 함께 만들 때 지키는 규칙
└─ README.md       이 문서
```
