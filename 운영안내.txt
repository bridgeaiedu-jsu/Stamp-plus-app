==============================================================
  브릿지카페 단골 적립 스탬프  -  매장 운영 안내
==============================================================

이 안내는 "컴퓨터를 잘 모르는 직원"도 그대로 따라 할 수 있게 썼어요.
막히면 맨 아래 "문제가 생겼을 때"를 먼저 보세요.


--------------------------------------------------------------
0. 시작하기 전에 (사장님이 한 번만 적어 두세요)
--------------------------------------------------------------

  * 사장님 화면 주소  : _______________________________________
  * 비밀번호 (4자리)  : (사장님께 직접 물어보세요. 여기에 적어 두지 마세요)
  * 사장님 화면을 여는 기기 : 가게 휴대폰 / 태블릿  (항상 이것만 쓰기!)

  [꼭 기억하세요]
  - 스탬프 기록은 "이 기기 안에만" 저장돼요.
    그래서 항상 "같은 기기, 같은 브라우저(인터넷 앱), 같은 주소"로
    열어야 해요. 다른 기기나 다른 주소로 열면 기록이 없는 것처럼 보여요.
  - 홈 화면에 바로가기를 만들어 두면 편해요. (사장님께 부탁하세요)

  [적립 규칙]  (사장님이 정한 규칙에 맞게 고쳐 쓰세요)
  - 음료 1잔당 스탬프 1개
  - 스탬프 10개를 모으면 아메리카노 1잔 무료
  - 손님은 "휴대폰 번호 뒷 4자리"로 구분해요. (이름은 받지 않아요)


--------------------------------------------------------------
1. 손님에게 이렇게 말씀하세요 (예시 문구)
--------------------------------------------------------------

  ● 처음 오신 손님께
    "저희 가게는 스탬프 적립이 있어요. 음료 1잔에 스탬프 1개,
     10개 모으시면 아메리카노 1잔이 무료예요.
     휴대폰 번호 뒷 4자리만 알려주시면 바로 적립해 드릴게요."

  ● 번호를 물어볼 때
    "휴대폰 번호 뒷 4자리만 말씀해 주시겠어요?
     이름이나 다른 정보는 받지 않아요."

  ● 적립한 뒤에
    "적립됐어요! 지금 ○개 모으셨어요. ○개 더 모으시면 무료예요."

  ● 지금 몇 개인지 물어보실 때
    "확인해 드릴게요. 번호 뒷 4자리 말씀해 주세요."
    (사장님 화면에서 [개수만 보기]를 눌러 알려 드려요)

  ● 10개를 모으셨을 때
    "축하드려요! 스탬프 10개를 다 모으셨어요.
     오늘 아메리카노 1잔 무료로 드릴게요!"

  ● 손님이 QR을 찍어서 "스탬프가 안 보여요" 하실 때
    (손님 휴대폰에는 "스탬프는 가게에서 확인해 드려요"라고만 나와요)
    "손님 휴대폰에서는 스탬프 개수가 보이지 않아요.
     저희가 가게에서 바로 확인해 드릴게요. 번호 뒷 4자리 알려주세요."

  ● 같은 분이 한 번에 두 잔을 사셨을 때
    (두 잔이면 스탬프 2개) "두 잔이시니까 2개 적립해 드릴게요."
    -> 적립 버튼을 두 번 눌러요. (아래 "2. 적립하는 법" 참고)


--------------------------------------------------------------
2. 사장님 화면 들어가는 법
--------------------------------------------------------------

  1) 가게 기기에서 사장님 화면 주소(또는 홈 화면 바로가기)를 눌러요.
  2) "비밀번호"에 숫자 4자리를 넣고 [들어가기]를 눌러요.
  3) "사장님 화면"이 나오면 성공이에요.

  [알아 두세요]
  - 비밀번호를 3번 틀리면 30초 동안 잠겨요. 30초 뒤에 다시 하면 돼요.
  - 한 번 들어가면 앱을 닫기 전까지는 다시 묻지 않아요.
  - 자리를 비울 때는 오른쪽 위 [잠그기]를 누르세요.
    (손님이 화면을 만지거나 보지 못하게 하려는 거예요)


--------------------------------------------------------------
3. 적립하는 법  (손님이 음료를 사셨을 때)
--------------------------------------------------------------

  1) 손님께 "번호 뒷 4자리"를 여쭤봐요.
  2) 맨 위 칸에 그 숫자 4개를 넣어요.
     - 4자리를 다 넣기 전에는 버튼이 회색이라 눌리지 않아요. 정상이에요.
  3) 큰 파란 버튼 [적립]을 눌러요.
  4) 화면에 이렇게 나오면 끝이에요.
       "적립했어요! (3개)"
       그리고 동그라미에 지금 개수만큼 색이 채워져요.
  5) 손님께 개수를 알려 드려요.

  [같은 손님에게 1분 안에 또 적립하려고 하면]
  - "잠깐만요! 방금 적립했습니다. 계속할까요?" 라는 창이 떠요.
    * 정말 한 번 더 적립해야 하면 -> [계속 적립]
    * 실수로 두 번 누른 거라면      -> [그만두기]
  - 이 창은 실수로 두 번 적립되는 걸 막아 주는 장치예요.

  [그냥 개수만 알고 싶을 때]
  - 번호를 넣고 [개수만 보기]를 누르세요. 아무것도 바뀌지 않아요.

  [오늘 몇 번 적립했는지]
  - 화면 맨 아래 "오늘 적립한 총 횟수"에 나와요. (날이 바뀌면 0부터)


--------------------------------------------------------------
4. 실수했을 때 되돌리는 법
--------------------------------------------------------------

  ● 같은 손님에게 적립을 잘못 눌렀을 때 (1개 너무 많이 적립)
    1) 같은 번호를 넣어요.
    2) [취소 (-1)]를 눌러요. -> 스탬프가 1개 줄어요.
    (두 번 잘못 눌렀으면 취소도 두 번 누르세요)

  ● 번호를 잘못 넣고 [적립]을 눌렀을 때 (다른 사람 번호에 적립됨)
    1) "잘못 넣었던 그 번호"를 다시 넣어요.   <- 이게 중요해요!
    2) [취소 (-1)]를 눌러요.
    3) 이제 "맞는 번호"를 넣고 [적립]을 눌러요.
    (방금 취소한 직후에는 "방금 적립했습니다" 창이 뜨지 않아요)

  ● 취소는 이럴 땐 안 돼요
    - 스탬프가 0개인 번호는 뺄 게 없어서 "0개라서 뺄 게 없어요"라고 나와요.
    - 취소는 한 번에 1개씩만 돼요.


--------------------------------------------------------------
5. 무료 음료 드리고 초기화하는 법
--------------------------------------------------------------

  ● 스탬프가 10개가 되는 순간
    - 화면 맨 위에 초록색 큰 글씨
        "무료 음료 제공 대상입니다"
      가 나오고, 휴대폰이 짧게 진동해요.
    - 이 글씨는 "사용 완료"를 누를 때까지 그 번호를 넣을 때마다 보여요.
    - 10개인 상태에서는 [적립]을 눌러도 11개가 되지 않아요.
      ("이미 10개예요. 무료 음료를 드린 뒤 '사용 완료'를 눌러 주세요")

  ● 무료 음료를 드린 뒤에 (순서가 중요해요!)
    1) 먼저 무료 아메리카노를 만들어서 손님께 드려요.
    2) 그 손님 번호 4자리를 넣어요.
    3) 초록색 [사용 완료]를 눌러요.
    4) "무료 음료를 드렸나요?" 확인창이 떠요.
         * 드렸다면 -> [네, 사용 완료]  (스탬프가 0개로 초기화돼요)
         * 아직이면 -> [아니요]
    5) "사용 완료! 0개로 초기화했어요."가 나오면 끝이에요.

  [주의]
  - [네, 사용 완료]를 누르면 되돌릴 수 없어요.
    음료를 드리기 "전에" 누르지 마세요.
  - 10개가 아닌 손님에게 [사용 완료]를 누르면
    "아직 10개가 아니에요"라고 나오고 아무것도 바뀌지 않아요.


--------------------------------------------------------------
6. 문제가 생겼을 때 확인할 것 3가지
--------------------------------------------------------------

  [문제 1]  스탬프 기록이 사라졌어요 / 손님이 "저 쌓였는데요?" 해요
  ------------------------------------------------------------
    확인 1) 평소 쓰던 "그 기기"가 맞나요?  (다른 휴대폰/태블릿이면 기록이 없어요)
    확인 2) 평소 쓰던 "그 인터넷 앱(브라우저)"과 "그 주소"가 맞나요?
            - 비공개(시크릿) 창이나 다른 브라우저, 주소가 조금만 달라도
              기록이 안 보여요.  평소 쓰던 홈 화면 바로가기로 다시 열어 보세요.
    확인 3) 그래도 없으면, 사장님께 알리세요.
            - 사장님이 저장해 둔 "백업 파일"로 되돌릴 수 있어요.
              (사장님 화면 맨 아래 [백업 파일 불러오기])
    ※ 예방: 사장님이 일주일에 한 번 [백업 파일 저장]을 눌러 두세요.
            (화면 아래에 "마지막 백업" 날짜가 나와요. 오래되면 빨간 글씨로 알려 줘요)

  [문제 2]  버튼이 안 눌려요 / 화면이 안 열려요
  ------------------------------------------------------------
    확인 1) 번호 4자리를 모두 넣었나요?  (3자리 이하면 버튼이 회색이에요)
            숫자 말고 다른 글자가 들어가면 자동으로 지워져요.
    확인 2) 화면에 확인창("잠깐만요!", "무료 음료를 드렸나요?")이 떠 있나요?
            -> [그만두기]/[아니요]/[네...] 중 하나를 먼저 눌러야 뒤 화면이 눌려요.
    확인 3) 비밀번호 화면에서 멈췄다면:
            - "30초 뒤에 다시 해 주세요"라고 나오면 30초만 기다리세요.
            - 그래도 안 되면 화면을 새로고침(당겨서 내리기)하고,
              그래도 안 되면 사장님께 비밀번호를 다시 확인하세요.

  [문제 3]  개수가 이상해요 (손님이 아는 개수와 다르거나, 손님 휴대폰에서 개수가 안 보여요)
  ------------------------------------------------------------
    확인 1) 사장님 화면에서 그 번호로 [개수만 보기]를 눌러 보세요.
            - 이게 "진짜 개수"예요.
    확인 2) 손님 휴대폰에서 QR로 본 화면은 "가게 기록"을 볼 수 없어요.
            - 손님 휴대폰에는 "스탬프는 가게에서 확인해 드려요"가 나와요.
            - 개수는 가게 기기에서만 정확해요.
    확인 3) 번호가 같은 다른 손님은 없나요?
            - 뒷 4자리만 쓰기 때문에 서로 다른 두 손님의 뒷 4자리가
              같을 수 있어요. 이럴 땐 사장님과 상의해서 정하세요.

  그래도 해결이 안 되면: 화면을 그대로 두고 사장님께 사진이나 말로 알려 주세요.
  (연락처: ______________________)


--------------------------------------------------------------
7. 손님 정보 지키기 (꼭 지켜 주세요)
--------------------------------------------------------------

  - 손님 번호는 "뒷 4자리"만 사용해요. 전체 번호나 이름은 묻지 않아요.
  - 번호를 종이나 휴대폰 메모, 메신저에 따로 적어 두지 마세요.
  - 손님이 사장님 화면을 보지 못하게 하세요. 자리를 비울 때는 [잠그기].
  - 비밀번호를 손님에게 알려주거나 눈에 보이는 곳에 붙여 두지 마세요.
  - 백업 파일에는 손님 번호가 들어 있어요.
    인터넷에 올리거나 다른 사람에게 보내지 마세요.

8. 하루 마감 체크 (1분)
--------------------------------------------------------------

  [ ] 사장님 화면 맨 아래 "오늘 적립한 총 횟수"가 장부(영수증)와 비슷한가요?
  [ ] 무료 음료를 드렸는데 [사용 완료]를 안 누른 손님은 없나요?
  [ ] 화면 오른쪽 위 [잠그기]를 눌렀나요?
  [ ] (일주일에 한 번) [백업 파일 저장]을 눌렀나요?
